# IceAndStreet ⛸️

O **IceAndStreet** é um blog focado no universo da patinação artística em suas diversas modalidades. O objetivo do projeto é funcionar como um guia informativo, explicando as funções, características e diferenças entre os principais tipos de patins utilizados por entusiastas e profissionais.

O site aborda modalidades como:
* **Patins Artístico no Gelo** (Ice Skating)
* **Patins Inline** (Rollerblade)
* **Patins Quad** (Tradicional de 4 rodas)
* **Patins de Rock / Rockered** (Configuração específica para maior manobrabilidade)

## 🚀 Funcionalidades e Interações

O projeto conta com páginas dinâmicas e interativas para melhorar a experiência do usuário, incluindo:
* **Interação Funcional:** Elementos interativos via JavaScript para navegação e exibição de conteúdos dinâmicos.
* **Seções Informativas:** Explicações detalhadas sobre as funções de cada tipo de patins.
* **Design Responsivo:** Adaptado para leitura tanto em computadores quanto em dispositivos móveis.

## 📦 Como Executar o Projeto Localmente

Para clonar e rodar este projeto na sua máquina, você precisará ter o [Git](https://git-scm.com) e o [Node.js](https://nodejs.org) instalados.

### 1. Clonar o Repositório

Abra o terminal e clone o projeto (certifique-se de acessar a branch de desenvolvimento `dev` se for o caso):

```bash
# Clonar o repositório
git clone [https://github.com/Heringson/IceAndStreet.git](https://github.com/Heringson/IceAndStreet.git)

# Entrar na pasta do projeto
cd IceAndStreet

# Mudar para a branch dev (onde estão as atualizações mais recentes)
git checkout dev
